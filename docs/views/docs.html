TROUBLESHOOTING

Frequently Asked Questions

Why does the dashboard stay Offline?
Confirm a valid PAT is saved, start the backend, and inspect System Audit Logs. The bridge needs permission to dispatch the workflow and read job logs.
Why is the Ngrok URL not discovered?
Check that the workflow completes successfully and that its logs contain an Ngrok URL in an accepted ngrok.app or ngrok.io format.
Why does an AI task fail?
Confirm GEMINI_API_KEY exists as a GitHub Actions repository secret and is passed into the backend workflow environment. Then inspect the task response.
How should prompts be designed?
State objective, constraints, output format, source requirements, and acceptance criteria. Let the decomposer create specialist roles.
