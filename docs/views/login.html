SECURITY SUMMARY

Enterprise Session Controls

  • OAuth access is granted by GitHub and can be revoked from your GitHub settings.
  • OAuth access and refresh tokens stay in session storage; non-secret profile metadata is kept separately.
  • Expiring OAuth tokens are refreshed when a refresh token is available.
  • Authenticated sessions are reused by GitHub Bridge and backend requests.
